# Воспроизводимая сборка

Python 3.12, DejaVu Sans/Serif (пакет `fonts-dejavu-core` в Ubuntu). Все иллюстрации, тексты, переводы интерфейсов и готовые скриншоты входят в репозиторий. После установки зависимостей PDF собираются без сети.

```bash
python -m pip install -r tools/requirements-pdf.txt
python tools/build_pdfs.py
python tools/validate_pdfs.py
```

Оригинальные PNG иллюстраций не ретушируются и не обрезаются. Внутри PDF применяется только JPEG-кодирование художественных изображений (качество 92) для умеренного размера файлов; документальные экраны сохраняются без JPEG-потерь. Текст находится в векторном слое, шрифты DejaVu встроены, ссылки имеют настоящие URI-аннотации.

Ранее опубликованные тексты сохранены по смыслу и полностью включены в новые PDF. Добавлены документальные пояснения и ссылка на библиотеку GitHub. Оригинальная редакция остаётся в Git-истории на commit `2e1c4de9c7d3a228f6cc77a0207ef5ddf9f753bd`.

## Происхождение изображений

Пять новых художественных сцен созданы с помощью ИИ для этого издания. Они не являются фотографиями готовых роботов или установленного оборудования. Переданный автором 20-страничный PDF использован как визуальный ориентир, не выдаётся за заново подтверждённую документацию оборудования.

12 скриншотов сняты с настоящих локальных программ: ВЕСТА, FIX10 и каталог инструментов. В иностранных версиях текстовые узлы интерфейса переведены до съёмки. Алгоритмы и показания симуляции не подменялись, пиксели после съёмки не ретушировались. Это редакционная локализация проверочных сборок, не выпуск многоязычных программ. Сведения о версиях и контрольные суммы: `assets/screens/provenance.json`.

Для повторного получения экранов нужны отдельные исходники локальных программ и Playwright; они не входят в библиотеку книг и не устанавливаются на VDS:

```bash
python tools/capture_programs.py --vesta-source /path/to/vesta-local --site-dist /path/to/website/dist --site-public /path/to/website/public --heating-html /path/to/labs/house-heating.html --output assets/screens
```

Сценарий допускает только собственные loopback-серверы, использует пустую временную историю, не обращается к production, реальной Ollama, микрофону или пользовательским аккаунтам. Проверка иностранных интерфейсов останавливает съёмку при оставшихся кириллических подписях.

## Публикация

PR проверяет готовые PDF и независимую пересборку. После согласованной публикации в main workflow создаёт публичный GitHub Release с четырьмя PDF, манифестом и SHA-256. Production сайта и его исходники не изменяются. Платные объявления и внешние рассылки workflow не создаёт.
