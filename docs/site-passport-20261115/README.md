## Содержание

- Назначение платформы, архитектура, данные и семь блок-схем.
- Заявки, модерация, отклики, выбор помощника, выполнение и подтверждение.
- Конструктор баннеров, редактор контента, формы, расчёты и инструменты.
- ВЕСТА, 81 справочная карточка, ограничения поиска и отсутствие фиктивных пользователей.
- Голос сайта, локальный Vosk, настройки и разрешения.
- **Самостоятельная Android-система — приоритет следующей разработки**, собственные экраны, SpeechRecognizer и Android TextToSpeech, общий API. Не WebView-оболочка.
- iOS — отдельный последующий проект, не готовое приложение.
- Роли, «Контроль ВЕСТА», безопасность, резервирование и совместимый откат.
- Предварительная стоимость разработки и сценарий эксплуатационного бюджета.

Каждая версия PDF содержит 15 страниц. Иллюстрации серии и реальные локальные снимки интерфейсов сопровождаются пояснениями. Схемы — редакционные векторные диаграммы, не снимки инфраструктуры. Снимок каталога инструментов не выдаётся за снимок конструктора баннеров. Иностранные интерфейсы локализованы для предыдущего издания; это не свидетельство многоязычной версии продукта.

## Оценка стоимости

Полная социальная платформа с нуля: **33 000–120 000 USD**, расчёт 1 100–2 000 часов по условной ставке 30–60 USD/час. Android MVP отдельно: **12 000–48 000 USD**. Вместе сайт и Android: **45 000–168 000 USD**. Необязательный следующий iOS-этап: ещё **10 800–43 200 USD**.

Это плановая оценка трудозатрат, не независимая оценка бизнеса, фактические расходы или коммерческое предложение. В паспорте есть условный пересчёт стоимости сайта в EUR при 1 EUR = 1,10 USD; он не является курсом на дату документа. Налоги, отдельный резерв, обучение большой модели, GPU, промышленная интеграция и продвижение не включены. Точные цены подтверждаются отдельным аудитом и предложениями исполнителей.

## Проверка и границы

[Результаты проверок документа](validation.json). Проверяются сохранность исходных абзацев и таблиц, семь диаграмм, язык, ссылки, контрольные суммы баннера, границы текста и отсутствие почти пустых страниц. Вёрстка проверена визуально. Это **не новые тесты сайта, безопасности, Android/iOS, микрофона или VDS**.

В исходниках обнаружены существенные ограничения, отражённые в паспорте: кандидат ВЕСТЫ требует другую схему БД; проверка прямого доступа к неодобренной заявке остаётся блокирующей; автоматическое одобрение поездки в просмотренном варианте связано с категорией, а не отдельной срочностью; бесплатная квота — пять откликов без срока и автоматического сброса; Microsoft Pavel нельзя обещать на Android/iOS; автономность распознавания зависит от движка и языка.

APK/AAB, приложение iOS, подпись мобильных приложений и реальное испытание устройств **не подготовлены этим комплектом**. Паспорта не устанавливают программы, не меняют базу, тарифы, VDS, исходные книги или рабочие приложения. Новый Release не создаётся.

Исходник содержания — `content.json`; тексты Markdown, PDF, манифест и проверки создаёт `tools/build_passports.py`. Для сборки на Linux нужны Python 3.12+, шрифты DejaVu и зависимости из корневого `tools/requirements-pdf.txt` книжного репозитория:

```bash
python3 -m pip install -r tools/requirements-pdf.txt
python3 docs/site-passport-20261115/tools/build_passports.py
```

Для чтения готовых PDF Python не требуется. Техническая и литературная приёмка владельцем остаётся отдельным действием.
