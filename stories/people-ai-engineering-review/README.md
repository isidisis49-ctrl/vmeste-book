## Что внутри

1. Сокращённое художественное начало: человек не решается попросить о помощи, затем сам помогает другому.
2. ВЕСТА: формулирование задачи и честное представление справочных карточек.
3. ТАШИ: личное рабочее место, документы и разрешённые файлы.
4. Инженерия: разница между моделью, измерением, прототипом и устройством.
5. Обобщённый промышленный пример: событие, документы, ремонт, роли сотрудников и сводка.
6. Ограниченный пилот, права доступа, проверяемые источники и ответственность человека.
7. Реальный локальный снимок симулятора с объяснением его границ.
8. Ссылки на сайт, книги, сообщества, ботов и добровольную поддержку.

В каждом PDF — 9 страниц. Использованы иллюстрации серии и новая иллюстрация из трёх сцен. Изображения не содержат специально добавленных языковых подписей. Интерфейс симулятора локализован редакционно для каждой версии; это не заявление о выпуске многоязычного продукта.

[Полный самостоятельный рассказ на русском «Есть к кому обратиться»](../EST_K_KOMU_OBRATITSYA_RU.md) сохранён отдельно. В новом томе использован сокращённый пересказ; полные переводы большого рассказа не заявляются.

## Воспроизводимая сборка

Исходник содержания — `editions.json`; `text/BOOK_*.md` — его читаемые представления. Скрипт не загружает модели и не обращается к production.

На Linux с Python 3.12+, системными шрифтами DejaVu и зависимостями из корневого `tools/requirements-pdf.txt`:

```bash
python3 -m pip install -r tools/requirements-pdf.txt
python3 stories/people-ai-engineering-review/tools/build_review.py
```

Для другого пути checkout предусмотрен параметр `--repository`. Существующие PDF в `downloads/` скрипт не изменяет.
